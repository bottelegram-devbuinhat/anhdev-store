Đặt lại / cộng tiền và xem danh sách tài khoản vẫn làm trong Telegram bằng lệnh /admin (Set tiền, Cộng tiền, Xem tiền) hoặc /setmoney, /addmoney, /checkweb. Trình duyệt không gửi được token bot qua API nên trang web chưa làm được phần này. Muốn đưa số dư lên web thì cần sửa CORS ở backend.
